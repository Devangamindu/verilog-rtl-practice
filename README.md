# Verilog RTL Practice

## Overview

A collection of Verilog HDL practice problems and small RTL designs developed to strengthen my fundamentals in digital logic and RTL design.

The repository contains implementations covering combinational logic, sequential logic, arithmetic circuits, counters, registers, multiplexers, encoders, FSMs, and other digital design concepts.

## Topics Covered

### Combinational Logic

- Multiplexers
- Encoders and decoders
- Comparators
- Parity logic
- Arithmetic circuits
- Boolean logic

### Sequential Logic

- Flip-flops
- Counters
- Shift registers
- SISO registers
- Clock-related logic
- Edge detection

### Arithmetic and Data Processing

- Full adder
- Ripple-carry adder
- Binary multiplier
- Average calculation
- Factorial
- Number manipulation

### FSM and Control Logic

- Sequence detection
- Traffic-light control
- State-based control logic
- Pattern detection

### Other RTL Exercises

- Binary-to-Gray conversion
- Zero counting
- Number ordering
- Swapping logic
- Modulo counters
- Multiplexer implementations

## Tools

- Verilog HDL
- Xilinx Vivado
- Vivado Simulator

## Purpose

This repository documents my continuous practice in Verilog HDL and RTL design.

The exercises helped me strengthen:

- Digital logic fundamentals
- Verilog syntax
- Combinational and sequential modeling
- FSM design
- RTL coding practices
- Simulation and waveform debugging

## Progress

These exercises were developed progressively as part of my RTL learning journey and complement my larger protocol, memory, and SoC-level projects.
